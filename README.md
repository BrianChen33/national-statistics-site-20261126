Singapore in Numbers — a national statistics site for Singapore. It runs in a web browser from static files with no network request, on a desktop and on a phone: an overview with the headline finding (nearly 1 in 5 residents is 65 or older), eight topic pages with charts and tables, a searchable data explorer covering every indicator, and a sources & method page. Every figure names its source and its year.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.

## Hand it in

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
